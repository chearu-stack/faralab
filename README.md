# FARALAB - Landing Page

## Концепция дизайна

Dark Premium Lab (темный фон, неоновые акценты, премиальный автосвет).

## Структура директорий

- `/img` — хранение изображений, текущий файл: `fon.jpg`
- `/temp` — папка для временных набросков и черновиков
- `index.html` — главный файл сборки

## Текущий статус

Этап 1. Инициализация и привязка главного фона.

## План разработки

- Рефакторинг блока контактов: замена единой кнопки WhatsApp на систему (телефонный звонок, Telegram, форма) и интеграция Яндекс.Карт для локального гео-позиционирования.
