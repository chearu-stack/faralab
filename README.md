# FARALAB - Landing Page

## Концепция дизайна

Dark Premium Lab (темный фон, неоновые акценты, премиальный автосвет).

## Структура директорий

- `/img` — хранение изображений:
  - `hero-bg.jpg` — главный фон
  - `workshop-lab.jpg` — мастерская FARALAB
  - `beam-stg.jpg` — светотеневая граница
  - `hero-promo.mp4` — промо-видео
  - `toyota-faralab-1.png` — Toyota FARALAB, кадр 1
  - `toyota-faralab-2.png` — Toyota FARALAB, кадр 2
- `/temp` — папка для временных набросков и черновиков
- `index.html` — главный файл сборки

## Текущий статус

Этап 1. Инициализация и привязка главного фона.

## План разработки

- Рефакторинг блока контактов: замена единой кнопки WhatsApp на систему (телефонный звонок, Telegram, форма) и интеграция Яндекс.Карт для локального гео-позиционирования.

## Этап 2: Премиум-трансформация (Сайт уровня 100k+ ₽)

- Интеграция фонового/промо-видео (`img/hero-promo.mp4`) в главный экран и секцию мастерской.
- Внедрение интерактивных миникаруселей/слайдеров (по типу Voge) для демонстрации работ, линз и оборудования.
- Увеличение визуальной плотности: блок «Технологический процесс», блок «Оборудование и ГОСТ», интерактивный прайс-калькулятор.
- Оптимизация под mobile-first: плавные свайпы, плавающая панель быстрого вызова (`tel:`, Telegram).
