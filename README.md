# FARALAB — Портфолио автосвета

FARALAB — landing page студии автосвета в эстетике Dark Premium Lab: тёмная визуальная основа, неоновые акценты и премиальная подача услуг.

## Технологический стек

- HTML5 — семантическая структура страницы;
- CSS3 — адаптивная вёрстка и Dark Premium Lab оформление;
- Vanilla JavaScript — интерактивность и динамическая галерея;
- Swiper.js — интерактивный слайдер портфолио;
- Яндекс.Карты — виджет расположения и построение маршрута.
