# FARALAB — Портфолио автосвета

FARALAB — landing page студии автосвета в эстетике Dark Premium Lab: тёмная визуальная основа, неоновые акценты и премиальная подача услуг.

## Технологический стек

- HTML5 — семантическая структура страницы;
- CSS3 — адаптивная вёрстка и Dark Premium Lab оформление;
- Vanilla JavaScript — интерактивность и динамическая галерея;
- Swiper.js — интерактивный слайдер портфолио;
- Яндекс.Карты — виджет расположения и построение маршрута.

## Развёртывание

Проект является статическим сайтом и не требует серверной части или специальной среды выполнения.

### Локальный просмотр

Скачайте или клонируйте репозиторий и откройте `index.html` в браузере.

Для корректной работы всех функций рекомендуется запускать проект через локальный HTTP-сервер.

### Публикация

Для публикации достаточно загрузить содержимое проекта на любой хостинг, поддерживающий статические сайты.

Структура проекта не требует привязки к GitHub Pages.

После размещения можно подключить собственное доменное имя.

### Что переносится

Для развёртывания используется весь каталог проекта:

- `index.html`;
- `css/`;
- `js/`;
- `img/`;
- `favicon.svg`;
- остальные необходимые файлы проекта.

Проект подготовлен как законченный автономный статический сайт и может быть перенесён с текущей площадки размещения на другой хостинг без изменения его основной структуры.

## Контакты и геолокация

- **Регион:** Нижегородская область.
- **Интеграции:** форма связи, прямые мессенджеры, виджет Яндекс.Карт и автоматическая маршрутизация интегрированы в соответствующий интерфейсный блок на самом сайте.

Проект готов к локальному просмотру и публикации.
