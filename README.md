# Портфолио FARALAB

FARALAB — landing page лаборатории автосвета в эстетике Dark Premium Lab: тёмная основа, неоновые акценты и премиальная подача автомобильной оптики.

## Технологический стек

- Семантический HTML5 без inline-стилей и inline-скриптов.
- Нативный JavaScript в `js/main.js`.
- CSS-компоненты, адаптивная сетка и mobile-first правила в `css/style.css`.
- Swiper.js для интерактивного портфолио.
- Виджет Яндекс.Карт и ссылка построения маршрута.
- Динамический загрузчик изображений с чередованием `gg_` и real-фотографий.

## Управление портфолио

Все изображения портфолио размещаются в `img/gallery/`. Загрузчик в `js/main.js` автоматически обнаруживает файлы с расширениями `.jpg`, `.jpeg`, `.png`, `.webp` и `.avif` через directory listing сервера. Для локального запуска без listing используется fallback-список актуальных активов.

Перед выводом файлы разделяются на две группы: имена с префиксом `gg_` и остальные реальные фотографии. Затем они чередуются по схеме `gg_ → real → gg_ → real`; оставшиеся изображения добавляются в конец. Все изображения выводятся с `loading="eager"` для немедленного отображения.
